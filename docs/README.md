# Platform Knowledge Cache

One file per platform or tool (e.g. `vapi.md`, `retell.md`, `twilio.md`, `calcom.md`).
Reused across clients — check here before researching, update after.

Each file starts with:

```
# <Platform>
Last verified: YYYY-MM-DD
```

Then: what it does, pricing, limits, API/setup steps, gotchas, and source links.
